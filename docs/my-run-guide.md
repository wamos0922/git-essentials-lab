# My Run Guide

**Prerequisites**
- Java 17+ (or whatever the project requires)
- Python 3.x (to run the launcher)
- Git

**How to run the demo**
```bash
python3 run.py demo
```


What the demo does
The demo starts a small library simulation, loads a few books, and shows how the search works (case‑insensitive after Exercise 01, etc.). It prints a short summary of the library state to the console.
